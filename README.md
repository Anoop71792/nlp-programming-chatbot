# NLP Programming Chatbot

An NLP-based chatbot developed using Python and Flask to identify programming-related topics and provide relevant learning resources, tutorials, and responses.

The chatbot uses machine learning and NLP techniques to classify user queries, identify programming concepts, and recommend useful resources through an interactive web interface.

---

## Features

- Programming topic identification using NLP
- Machine learning-based query classification
- Resource recommendation system
- Web scraping integration
- Interactive chatbot responses
- Learning resource validation
- Dynamic response generation
- Beginner-friendly programming assistance

## System Workflow

1. User enters programming-related query
2. NLP module preprocesses the text
3. Machine learning model classifies the query topic
4. Relevant programming resources are collected
5. System validates useful links and responses
6. Chatbot returns learning materials and responses to the user

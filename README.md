# NLP Programming Chatbot

An NLP-based chatbot developed using Python and Flask to identify programming-related topics and provide relevant learning resources and responses.

## Features
- Programming topic identification using NLP
- Machine learning-based query classification
- Resource recommendation system
- Web scraping integration
- Interactive chatbot responses

## Technologies Used
- Python
- Flask
- NLP
- Random Forest Algorithm
- HTML
- CSS
- JavaScript
- Web Scraping
